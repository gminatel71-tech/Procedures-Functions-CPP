# Procedures-Functions-CPP
Este projeto é feito especificamente para praticar, em C++, procedimentos e funções. 
- O arquivo descrito como "Procedures" é um sistema focado (e implementado apenas por procedimentos) para ser uma calculadora.
- O segundo sistema com a pasta escrita "Sistema RH" é um sistema funcional focado no cadastro, edição e remoção de cargos, simulando um sistema de informação corporativo.
